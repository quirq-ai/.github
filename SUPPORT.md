# Get help with quirq

Start with the repository's README and [XO Space documentation](https://docs.xo.builders/). A repository's own support instructions take precedence over this shared guide.

| You need help with | Where to go |
| --- | --- |
| Using XO Space, setup, or a workflow | [XO Space Discussions](https://github.com/quirq-ai/xo-space/discussions) |
| A reproducible bug or a feature request | Issues in the repository that owns the affected code; for XO Space, [open an issue](https://github.com/quirq-ai/xo-space/issues/new/choose) |
| A documentation correction | A pull request in the repository that owns the page, or [team@xo.builders](mailto:team@xo.builders) when you need help finding it or issues are disabled |
| A hosted account, access, or billing question | [team@xo.builders](mailto:team@xo.builders) |
| A suspected security vulnerability | Our [private reporting instructions](https://github.com/quirq-ai/.github/blob/main/SECURITY.md) |

For technical help, describe what you are trying to do, the steps you took, and what happened. Include the relevant version or commit, operating system, installation method, and error message when available. Screenshots or a small reproduction can make the problem easier to understand.

Before sharing logs or screenshots, remove API keys, tokens, cookies, private project content, and personal information. Keep account details in email rather than public issues or discussions.
