# Contributing to quirq

Thanks for helping make agent work easier to start, understand, and improve. Bug reports, documentation corrections, thoughtful questions, and focused code changes are all welcome.

These are shared guidelines for quirq repositories. Follow the repository's own contribution, setup, testing, and license instructions when they are available.

## Find the right place

- **Questions and ideas:** join [XO Space Discussions](https://github.com/quirq-ai/xo-space/discussions).
- **Bugs:** open an issue in the repository that contains the affected code. Include what happened, what you expected, and a small reproduction.
- **Documentation:** suggest a correction in the repository that owns the page. If its issues are disabled, open a pull request or email [team@xo.builders](mailto:team@xo.builders) with the page URL.
- **Security:** use the [private reporting instructions](https://github.com/quirq-ai/.github/blob/main/SECURITY.md). Keep vulnerability details out of public issues and pull requests.

Search existing issues and pull requests before starting. Small fixes can go straight to a pull request; discuss substantial features or behavior changes first so we can agree on the problem and approach.

## Make a change

1. Read the target repository's README and contribution guide. Follow its setup, branch, and validation instructions.
2. Keep the change focused and explain the user problem it solves. Update related documentation when behavior changes.
3. Run the relevant checks. For documentation, verify links and rendered formatting; for code, exercise the affected behavior and follow the repository's test requirements.
4. Open a pull request with the reason for the change, a related issue if there is one, and what you verified. Call out anything you could not check. Include screenshots when they help explain a visual change.

**XO Space:** branch from and target `main`; `development` is the maintainers' staging branch, so do not target it. Follow its [contribution guide](https://github.com/quirq-ai/xo-space/blob/main/CONTRIBUTING.md) for setup and required checks.

**This `.github` repository:** target `main`. Profile, routing, and community-file changes should keep public links accurate and inherited guidance useful across repositories.

Check the target repository's license and contribution terms before submitting. This shared guide does not grant a license to other repositories or replace their terms.

## AI-assisted contributions

AI-assisted work is welcome. The person submitting a contribution is responsible for understanding the change, checking its accuracy, and validating the result. Explain meaningful limitations or unverified behavior in the pull request. Never include credentials, private conversations, personal data, or material you do not have permission to share.

Please follow our [Code of Conduct](https://github.com/quirq-ai/.github/blob/main/CODE_OF_CONDUCT.md). Be specific, patient, and open to feedback during review.
